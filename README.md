Fashion AR - Fashion E-commerce with Augmented Reality

About the Project

Fashion AR is a fashion e-commerce project designed to provide an interactive online shopping experience. It includes an Augmented Reality (AR) try-on concept and AI-based features.

Features

- Fashion e-commerce interface
- AR try-on functionality
- AI-based features
- Product browsing

Technologies Used

- Next.js
- React
- TypeScript (if used in the project)
- Supabase

Installation and Setup

1. Clone or download this repository.

2. Install dependencies:
   
   npm install

3. Create a ".env.local" file in the project root and add your own Supabase Project URL and Publishable Key:
   
   NEXT_PUBLIC_SUPABASE_URL=your_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_publishable_key

4. Start the development server:
   
   npm run dev

5. Open http://localhost:3000 in your browser.
